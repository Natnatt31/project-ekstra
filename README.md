# 🎮 Globaliti Esport Badung

Website profil statis resmi **Globaliti Esport Badung** — organisasi esport berbasis di Kabupaten Badung, Bali.

## 🚀 Tech Stack

- **HTML5** — Struktur konten
- **CSS3 + Tailwind CSS v3** — Styling responsif
- **JavaScript** — Interaktivitas
- **Particles.js** — Efek partikel hero section
- **Swiper.js** — Carousel roster & sponsor
- **AOS.js** — Animasi scroll
- **Animate.css** — Animasi masuk
- **Font Awesome 6** — Ikon
- **GLightbox** — Galeri lightbox
- **Google Fonts** — Orbitron & Nunito

## 📁 Struktur Proyek

```
├── index.html              # Halaman utama
├── assets/
│   ├── css/style.css       # Custom stylesheet
│   ├── js/
│   │   ├── main.js         # Script utama
│   │   ├── particles.config.js
│   │   └── swiper.init.js
│   └── images/             # Aset gambar
├── README.md
└── .gitignore
```

## 🛠 Setup & Development

1. Clone repository:
   ```bash
   git clone https://github.com/username/globaliti-esport-badung.git
   ```

2. Buka `index.html` di browser, atau gunakan Live Server:
   ```bash
   npx serve .
   ```

## 🌐 Deployment

### GitHub Pages
1. Push ke branch `main`
2. Settings → Pages → Source: `main` / `/ (root)`
3. Akses di: `https://username.github.io/globaliti-esport-badung/`

### Netlify
1. Connect repository atau drag & drop folder
2. Build command: _(kosong)_
3. Publish directory: `/`
